# Henry Adams, drawn (not at random)

A one-page recreation of the Life and Story stages from [anyhumanever.com](https://anyhumanever.com) for
Henry Brooks Adams (1838–1918), using the site's own layout and vocabulary and Adams'
own third-person reckonings from *The Education of Henry Adams*.

Static: `index.html` + two preview images. No build. The design belongs to Any Human Ever;
this is homage, not affiliation.
